## 2. 静态 TF 干跑（无雷达、无电控）

底盘仍在 `map` `(3.0, 1.5, 0)`，枪口相对底盘 `+0.4 m`。这是公式回归旧几何，**不要**改成产品站位还声称同一验收。产品主吊射位在 `itl_shoot`。目标是蓝方基地中间偏平大装甲 `(25.603, 8.000, 1.602)`。换算见 `docs/修改说明.md`。

```bash
source /opt/ros/jazzy/setup.bash
source /home/jlcv/heavy/install/setup.bash
ros2 launch heavy_lob_shot_manager dry_run.launch.py
```

应看到：

- `/lob_shot/status` 到达 `READY`
- 日志 `DRY_RUN PASS pitch≈33.27 deg z=1`（高抛约 59.66° 超过 `pitch_max_deg=42`，落地用平射支；watch 只验 10–42°，不把仰角硬卡 42°）
- watch 退出后 launch 结束

另开终端开火（仍不接电控，只看话题）：

```bash
source /opt/ros/jazzy/setup.bash
ros2 topic pub --once /lob_shot/fire std_msgs/msg/Bool "{data: true}"
```

此时 `z` 应变为 `2`。再发 `data: false` 回到 `1`。

取消吊射（节点应停止发 `/gimbal_command`）：

```bash
ros2 topic pub --once /lob_shot/trigger std_msgs/msg/Bool "{data: false}"
```

模拟未装枪（应进入 `INHIBITED`，不发云台）：

```bash
ros2 topic pub --once /lob_shot/module_docked std_msgs/msg/Bool "{data: false}"
```

干跑 launch 里的静态 TF 与自动 trigger 由 `/home/jlcv/heavy/src/heavy_lob_shot_manager/launch/dry_run.launch.py` 拉起。

## 2b. 按 ITL 执行吊射（无 Gazebo）

ITL `Simulation_shoot.launch.py` 的执行是：manager + RViz 看 Marker。本机 **不跑 Gazebo / Point-LIO**（Harmonic 整场 STL 太吃性能；ITL 那两段还依赖仿真雷达）。

```bash
source /opt/ros/jazzy/setup.bash
source /home/jlcv/heavy/install/setup.bash
export ROS_DOMAIN_ID=31
ros2 launch heavy_lob_shot_manager itl_shoot.launch.py
```

- 目标：蓝方基地中间偏平大装甲 `(25.603, 8.000, 1.602)`。ITL `(23.125, 1.510, 0.84)` 打在另一块 z≈0.83 台面上，不是底座。
- **主吊射区（梯形高地旁 +200 mm 小平面）**：整面可吊。演示 TF `map→base_link = (6.429, 11.690, 0.828)` 只是面上一点；高地顶不上。RViz 不画吊射区轮廓。换算见 `docs/修改说明.md`。
- 枪口仍 `base_link→muzzle` **+0.4 m**（车模/产品高度）。
- 演示点水平距约 19.53 m，高抛约 67.5° 超 `pitch_max_deg=42`，落地走平射支约 23.6°。
- RViz：`base_armor` 上/中/下三块板，中间板高亮；瞄准球在中间板中心。
- 2s 后自动 `/lob_shot/trigger`
- RViz：ITL `nav.rviz` 结构。三维场地 = 官方 `rmuc_2026.stl`（`/lob_shot/field_mesh` + `/prior_map`）。
- 仿真 Mid360 按官方点频：20 万点/s、10 Hz ≈ **625×32 ≈ 2 万点/帧**，视场 360°×(−7°~52°)，噪声 2 cm。话题 `/registered_scan`、`/livox/lidar`。
- 重定位实验 `reloc_icp`：ITL `performRegistration` 的 voxel+align 循环；本机无 small_gicp，用点到点 ICP。红点 `/reloc/scan_seeded` 是偏差初值，绿点 `/reloc/aligned` 是配准结果。

开火（不接电控，只看 `/gimbal_command` 的 z）：

```bash
export ROS_DOMAIN_ID=31
ros2 topic pub --once /lob_shot/fire std_msgs/msg/Bool "{data: true}"
```

`rmuc_sim.launch.py` / `gazebo.launch.py` 仍在包里，默认不要开。

模块门闩（装配完成后再允许瞄准）：

```bash

ros2 topic pub /lob_shot/module_docked std_msgs/msg/Bool "{data: true}"
ros2 topic pub /lob_shot/module_assembling std_msgs/msg/Bool "{data: false}"
ros2 topic pub --once /lob_shot/trigger std_msgs/msg/Bool "{data: true}"
```

串口仍用车上已有的 `jlcv_serial_driver`（`/home/jlcv/jlauto-aim/hero`），本仓库不启动它。吊射与电控联调前，可以只 `ros2 topic echo /gimbal_command`。

## 话题

| 话题 | 类型 | 方向 | 含义 |
| --- | --- | --- | --- |
| `/lob_shot/trigger` | `std_msgs/Bool` | 入 | true 开始，false 取消 |
| `/lob_shot/fire` | `std_msgs/Bool` | 入 | 仅 READY 时 true 则 `z=2` |
| `/lob_shot/module_unlocked` | `std_msgs/Bool` | 入 | 使用权解锁 |
| `/lob_shot/module_docked` | `std_msgs/Bool` | 入 | 42mm 模块已对接 |
| `/lob_shot/module_assembling` | `std_msgs/Bool` | 入 | 装配中（发射机构断电） |
| `/joint_states` | `sensor_msgs/JointState` | 入 | 实车反馈；名 `pitch_joint` `yaw_joint` |
| `/gimbal_command` | `geometry_msgs/Vector3` | 出 | 与自瞄同一合同；空闲不发 |
| `/lob_shot/status` | `std_msgs/String` | 出 | 状态机名字 |
| `/lob_shot/ready_to_shoot` | `std_msgs/Bool` | 出 | 仅表示瞄准完成，不是开火 |
