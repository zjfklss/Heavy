# 本队注释规范（jl_sp_vision / Heavy）

- **WHY 非 WHAT**（SkillsBot / 整洁之道）：写「为何与同济/英雄约定不同」，少写复述代码。
- **短名 + Lean**：少防御性长注释；选支写清后果。
- **吊射选支**：注明永远低抛、超限 inhibit、高抛只日志不瞄准。
