# 重装吊射迁同济

## 主目标

Heavy 吊射 + 英雄自瞄进同济无 ROS 工程。通信能抄同济合同则抄（`Command` / mode 0/1/2）；电控用自家 `0xA5/0x5A`。

开发机：`~/jl_sp_vision`  
英雄小电脑：`~/Heavy`（GitHub [zjfklss/Heavy](https://github.com/zjfklss/Heavy)）

## 已落地（2026-10-12）

1. 永远低抛 + `pitch_max` inhibit + 门闩 + 风车  
2. `0xA5` / `0x5A` + CRC；`heavy_lob` 干跑 / 实串口  
3. 钉头 `nail_mode`（EKF 转速用 `[7]`，已修同济误用 `[8]`）  
4. 圆点标定主路径（7×7@25）  
5. **`heavy_standard`**：同济 `mt_standard` 循环 + `HeroBoard`  
   - 自瞄/打符：同济 pitch 抬头为负 → 下发翻号  
   - 吊射：抬头为正，不翻；20 ms 节拍  
   - **本轮仅短焦**  
6. 小电脑全量编译 `build_full`，离线测 pitch≈33.27°

## 未做 / 本轮不做

- 长焦切换与双内参  
- 串口动态切 buff/lob（目前主要靠 yaml `mode`）  
- 步兵/哨兵产品化；push 同济上游（意见草稿可开 issue）

## 编译运行

### 吊射 only

```bash
cd ~/jl_sp_vision   # 或 ~/Heavy
cmake -B build_lob -DHEAVY_LOB_ONLY=ON
cmake --build build_lob -j
./build_lob/heavy_lob_offline_test
./build_lob/heavy_lob configs/heavy_lob.yaml --once
```

### 上车主入口（需 OpenVINO + 海康）

```bash
cd ~/Heavy
source /opt/intel/openvino_2024.6.0/setupvars.sh
cmake -B build_full -DHEAVY_LOB_ONLY=OFF
cmake --build build_full -j --target heavy_standard heavy_lob
./build_full/heavy_standard configs/heavy_standard.yaml
```
