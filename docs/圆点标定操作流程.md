# 小圆点板内外参标定操作流程

主路径：英雄对称圆点阵 **7×7，圆心距 25mm**（白底黑点）。无 ROS。

详细配置：`configs/calibration.yaml`  
内参文件：`configs/camera_info.yaml`  
手眼结果：`configs/calibration_result.yaml`  
旧大板（旁路）：`configs/calibration_legacy_10x7.yaml`

**CLI 一律用 `--key=value`。** OpenCV 的 `-c path` 空格写法会把 path 吃成 bool。

---

## 0. 板与环境

1. 使用 **7×7 对称小圆点板**，圆心距必须与 yaml 里 `center_distance_mm: 25` 一致（卷尺量相邻圆心）。
2. 板贴硬平面，勿翘曲；白底黑点（`blob_color: 0`）。黑底白点时改为 `255`。
3. 光照均匀，避免强反光把圆点冲掉。
4. 海康走 USB3；先跑 MVS 的 `set_usbfs_memory_size.sh`、`set_usb_priority.sh`。
5. 用户需在 `dialout` 组（串口姿态）：`sudo usermod -aG dialout $USER` 后重新登录。

云台轴不共点时保持（或改实测）：

```yaml
p_yaw_to_pitch_mm: [62.11, 0.0, 151.32]
p_pitch_to_barrel_mm: [0.0, 0.0, 0.0]
```

共点云台把两项都改成 `[0, 0, 0]`。

## 2. 采图

```bash
mkdir -p assets/intrinsic assets/handeye
# 内参手法时 --output-folder=assets/intrinsic
# 手眼手法时 --output-folder=assets/handeye
./build/capture \
  --config-path=configs/calibration.yaml \
  --output-folder=assets/intrinsic \
  --attitude=serial
```

同济 CAN 姿态（少用）：`--attitude=can`。

### 操作

| 键 | 作用 |
| --- | --- |
| `s` | 保存当前帧：`N.jpg` + `N.txt`（四元数 **wxyz**） |
| `q` | 退出 |

预览用降采样检测（面积阈值按 `detect_scale²` 缩小）。按 `s` 时全分辨率复检。0x5A 的 yaw/pitch 是**弧度**，画面上的 pitch 是关节角（绕 -Y），和手眼窗口的 `joint pitch` 是同一个数。存盘四元数按英雄 URDF 合成（yaw 绕 +Z，pitch 绕 -Y）。

串口在采图全程后台读。拿图像入队时间和最近一包 0x5A 比，超过 `attitude_skew_ms`（yaml，默认 20；命令行 `--skew-ms=` 可覆盖）不保存。对称圆点若反转后和上一张更接近，会翻转点序，姿势差得大也适用。两套手眼都用竖直板模型。解出的 `R_camera2gimbal` 已是 OpenCV 相机系，直接给 solver，不要再乘光学系。

轴偏置接近 0 时 `calibrate_robotworld_handeye` 会直接退出，改走 `calibrate_handeye`。上车瞄准用的外参以 URDF 固定关节为准，手眼结果用来核对，不要覆盖光学系 `-π/2, 0, -π/2`。

产物是连续编号的 `1.jpg` + `1.txt`、`2.jpg` + `2.txt`……内参和手眼分两个文件夹采，不要混在一起。

### 操作手法

内参和手眼是两种手法。内参挪板、云台尽量不动。手眼板和车都不动，只转云台。

#### 准备

1. 7×7 小圆点板贴在硬平板上，不要翘。白底黑点朝相机。相邻圆心距用卷尺量过，必须是 yaml 里的 25 mm。
2. 光照均匀，避免反光把圆点冲白。
3. 先把云台摆到正前方、大致水平。画面上的 yaw、pitch 应接近 0。差很多就先别采：零位不对，后面全偏。不对时改 `R_gimbal2imubody`，不要先改解算。

#### 保存的时机

每个姿势先停稳，再按 `s`。转动中、手在抖时不要按。

画面上要同时满足再保存：

- `board OK`：49 个圆点都在，没有缺角。
- `sync OK`：这一帧图像和云台角度对得上。`sync --` 时按 `s` 不会保存，等它变 OK。

`q` 退出。

#### 内参：挪板

云台保持不动。人拿板，或把板放到不同位置。整块 7×7 都必须在画面里。

- 板分别出现在画面四角和中心，不要永远停在中间。
- 有近有远。
- 板要斜着放几种角度，不要全部正对相机。
- 大约 15–30 张。相邻两张姿势要有明显差别。

保存到 `assets/intrinsic`。

#### 手眼：板固定，只转云台

1. 板立在车前，贴牢或靠稳。用卷尺量板到云台转轴附近的水平距离，记在纸上。
2. 从这一刻起，板和车体都不要再动，人不要碰板。
3. 只动云台。左右（yaw）和抬头低头（pitch）都要转到比较大的范围。只转一个方向解不出来。
4. 每个姿势停稳，圆点齐全，再保存。被切掉一角的不要。
5. 不要转到带明显横滚的姿势。roll 超过约 2° 的照片，解算时会被丢掉。
6. 大约 10–20 张。相邻两张不要只差一点点。

保存到 `assets/handeye`。

#### 做完后怎么判断手法对不对

先跑内参，重投影平均小于 0.3 像素再用这套内参跑手眼。手眼终端里的「标定板到原点水平距离」和纸上的卷尺数对比。差得离谱就重采手眼那一组，先不要改解算参数。

当前车上两轴不共点，手眼用 `calibrate_robotworld_handeye`。轴偏置接近 0 时这个程序会退出，改用 `calibrate_handeye`，手法仍然是板固定、只转云台。

自瞄 yaml 贴 `R_camera2gimbal` 和 `t_camera2gimbal`。这是 OpenCV 相机系，solver 直接用。不要再乘 URDF 光学系 `-π/2 0 -π/2`，也不要拿这份结果去改那个关节。仓库里的 `camera_info.yaml` 标了 `source: remote_hero_untuned`，是旧英雄相机，本车内参跑完会覆盖它。

## 3. 内参

```bash
./build_lob/calibrate_camera assets/intrinsic \
  --config-path=configs/calibration.yaml \
  --camera-info=configs/camera_info.yaml \
  --preview=auto
```

| `--preview` | 行为 |
| --- | --- |
| `auto`（默认） | 闪过预览，不阻塞 |
| `manual` | 每张按任意键 |
| `none` | 无窗口（SSH 无显示时用） |

### 验收

- 终端打印平均重投影误差；经验上 **&lt;0.3 px 较好**，&gt;0.5 px 建议重采。
- 默认写出 `configs/camera_info.yaml`（ROS 格式）。
- 需要扁平字段时加：`--output=configs/intrinsics_flat.yaml`，再粘到任务 yaml / `calibration.yaml`。

固定 K3（`CALIB_FIX_K3`）。

## 4. 手眼（主路径：robotworld）

```bash
./build_lob/calibrate_robotworld_handeye assets/handeye \
  --config-path=configs/calibration.yaml \
  --camera-info=configs/camera_info.yaml \
  --output=configs/calibration_result.yaml \
  --preview=auto
```

### 看什么

1. 每帧 `[accepted]` / `[rejected]`（重投影默认上限 1 px，yaml `reproj_max_px` 或 `--reproj-max=`）。
2. 终端注释里的：
   - 相机相对理想安装的 yaw/pitch/roll
   - **标定板到原点水平距离**（卷尺核对）
   - 板相对竖直偏角
3. 写出：`R_camera2gimbal`、`t_camera2gimbal`（米）→ `configs/calibration_result.yaml`

### 落到任务配置

把 `R_camera2gimbal`、`t_camera2gimbal`（以及需要的 `R_gimbal2imubody`）粘进自瞄/打符 yaml（字段名同现有 `configs/mvs.yaml` 等）。  
参考样例（勿直接当本车外参）：`configs/calibration_result_hero_ref.yaml`。

含义：`xyz_gimbal = R · xyz_cam + t`。

## 6. 常见失败

| 现象 | 处理 |
| --- | --- |
| 预览一直 `board --` | 调 `blob_min_area` / `blob_max_area`；检查板规格与 yaml；光照 |
| 保存提示全分辨率未检出 | 靠近一点或调 blob；或临时 `--require-board=0` |
| `读内参失败` | 先跑内参写出 `camera_info.yaml`；CLI 用 `--camera-info=` |
| `无有效手眼样本` | 检查 `N.jpg`/`N.txt` 成对；放宽 `--reproj-max=` |
| 距离离谱 | 核对 `center_distance_mm`；填对 `p_yaw_to_pitch_mm` |
| yaw/pitch 叠字方向反 | 改 `R_gimbal2imubody` 后再采/再解 |
| CLI 参数变 `true` | 改用 `--config-path=...` 等号形式 |

## 7. 性能相关（已做）

- blob 检测器只创建一次，灰度缓冲复用
- 采图预览默认半分辨率检测；保存才全分辨率复检
- 离线默认 `--preview=auto`，避免每张 `waitKey(0)`
- JPEG `jpeg_quality`（默认 92）可在 yaml 调
