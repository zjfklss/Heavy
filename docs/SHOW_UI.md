# 英雄实时调试窗（`--show`）

`build/hero --show` 打开 Qt 调试窗；实车、无串口、离线视频和 `--simulation` 共用这一个窗口。窗口代码 `tools/jlcv_show/` 与 `sp_jlcv_aimer` 是同一份，所以标题显示“JLCV / 实时调试”。

```bash
./build/hero --no-fire --show                               # 实车，不发射
./build/hero --video=$HOME/records/xxx.avi --show           # 离线回放
./build/hero --simulation --show                            # 仿真
```

默认编译启用（`HERO_WITH_SHOW_UI=ON`），依赖 Qt5 Widgets（`qtbase5-dev`）。用 `-DHERO_WITH_SHOW_UI=OFF` 编译时，`--show` 退回旧的 OpenCV 重投影窗口。没有图形界面（SSH 未转发显示）时不要加 `--show`。

## 窗口内容

- **左上：相机画面。** 实车和回放模式下，绿色为跟踪目标各装甲板的重投影，红色为射击决策当前的瞄准点，左上角文字是云台 yaw / pitch（弧度）。仿真模式只用黄色画检测到的装甲板角点，跟踪结果看左下小窗。
- **左下：世界系装甲板。** 画首个跟踪目标的 `Target::armor_xyza_list()`：各板位置、受击面法线和瞄准点。车辆通常 4 块、前哨站 3 块；按 Solver 的固定倾角绘制（车辆 +15°、前哨站 −15°）。
- **右侧三条曲线，单位 °，显示最近 10 秒：**
  - **Yaw**：蓝线为发送，橙线为反馈，±180° 跨界时连续展开。
  - **Pitch**：发送与反馈，**英雄约定抬头为正**（与串口协议一致）。
  - **发射指令**：控制位是否为“发射”，0/1 阶梯线，表示指令电平，不表示命中。

## 数据从哪来

| 模式 | 反馈曲线 | 发送曲线 |
| --- | --- | --- |
| 实车 | 电控回传的 yaw/pitch，按其接收时间 | **成功写进串口**的那一帧（已经过反馈有效性门控和 `--no-fire`） |
| `--no-serial` / `--video` | 固定的 `--yaw` / `--pitch`，标为“离线固定姿态” | 射击决策的输出 |
| `--simulation` | 仿真器反馈，换算到世界系 | 回给仿真器的指令（世界系） |

控制位为 0 时发送曲线断开，不把无效指令的 0 画成真实转动。同一曲线中断超过 0.5 秒也会断线。

## 操作

- 右上角“暂停显示”或空格：冻结曲线和画面，方便观察。只暂停显示，自瞄、串口收发继续运行。再按一次回到实时。
- 关闭窗口或按 Esc：程序停止，等待当前相机读取或串口操作返回后退出，退出前发送“不控制”帧。

界面约 30 Hz 刷新，画面缩小后最多约 14 Hz 更新；视觉和串口在工作线程运行，历史数据有界，不影响自瞄帧率。

`src/hero_show.hpp` 只读取算法已有输出，没有修改检测、跟踪、预测和射击算法。
