# 操作手速查（重装）

先看这份，再看长 `readme.md`。

## 1. 这是什么

| 入口 | 干什么 | 编译 |
| --- | --- | --- |
| `heavy_standard` | **上车主入口**：短焦自瞄（钉头）+ 打符 + 吊射，英雄 `0xA5/0x5A` | 全量 `build_full` |
| `heavy_lob` | 只吊射，可干跑 / 单独串口联调 | `HEAVY_LOB_ONLY` 或全量 |

本轮**只做短焦**。电控切长焦会打警告，仍用短焦相机与内参。

| 模式 | 干什么 | 云台 |
| --- | --- | --- |
| 自瞄 / 前哨（`auto_aim` / `outpost`） | 检测跟踪 + 钉头（`nail_mode`） | 小陀螺时 yaw 钉车中心 |
| 打符（yaml 设 `small_buff` / `big_buff`） | 能量机关 | 同济 Buff 链 |
| 吊射（yaml 设 `lob`） | 先验点、永远低抛 | 约 20 ms 一拍 |
| 同济默认动头（未开钉头） | 每帧追板 | 重装小陀螺别用 |

## 2. 为什么要钉头

重装云台很重。对小陀螺如果「动头追板」，电机容易烧。  
正确打法：yaw 钉在敌车中心方向，等装甲转到射界再开火。

成熟参考（远程 `jlcv-pc`）：

- `/home/jlcv/jlauto-aim/hero/.../opti_solver.cpp` · `processAssessment2`
- 本仓：`configs/heavy_standard.yaml` / `configs/heavy_nail.yaml`（`nail_mode: true`）

## 3. 上车（英雄小电脑）

```bash
cd ~/Heavy
source /opt/intel/openvino_2024.6.0/setupvars.sh
./build_full/heavy_standard configs/heavy_standard.yaml
```

串口：`/dev/ttyUSB0` @ `921600`；下发 `0xA5`，回传 `0x5A`。

**上车前必做：**

1. 圆点标定换掉 yaml 里短焦占位（现仍是同济 `standard3`）
2. 接上海康短焦 + 串口 `/dev/ttyUSB0`（用户需在 `dialout`）
3. `device: GPU`（OpenVINO `available_devices` 含 GPU；无 GPU 时 `resolve_ov_device` 会回退 CPU）
4. 自瞄 pitch：同济抬头为负，下发到英雄时已自动翻号；吊射不翻

Git：`~/Heavy` 已接 `git@github.com:zjfklss/Heavy.git`，用小电脑密钥 `jlcv@jlcv-pc`。

## 6. 状态怎么读

| 日志 | 含义 | 怎么办 |
| --- | --- | --- |
| `Switch to lob` | 进吊射 | yaml `mode: lob` |
| `电控切长焦，本轮仅短焦` | 忽略长焦位 | 保持短焦 |
| `INHIBITED` | 门闩未开 | 确认模块；联调才改 yaml |
| `windmill block` | 弹道穿风车 | 改站位 |
| `low exceeds pitch_max` | 超俯仰限位 | 靠近或降目标 |
| `sender=DrySender` | 没写串口 | 查 port / 权限 |

## 7. 调参顺序

吊射：符号 → `base_yaw`（弧度）→ 几何 → `bullet_speed` → `friction`。  
钉头：`nail_spin_on` / `nail_spin_off`、`nail_fire_window_deg`。  
自瞄偏置：`yaw_offset` / `pitch_offset`（标定后再细调）。

## 8. 禁止

- 不要跑根目录 `autostart.sh`（指向旧 `sp_vision_25`）
- 不要拿未标定的 `standard3` 占位当真车内参上场
- 不要直接拿未改门闩的 `heavy_lob_robot.yaml` 上场
- `--loop --fire` 会持续开火
- **重装打小陀螺必须开 `nail_mode`**
