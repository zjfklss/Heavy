# 操作手速查（重装）

先看这份，再看长 `readme.md`。

## 1. 这是什么

本仓当前**能直接跑的是吊射**（`heavy_lob`）。  
**钉头自瞄**已抄进 `tasks/auto_aim/aimer.cpp`（`nail_mode`），算法来自远程英雄成熟方案；要跑通还需要相机、全量编译和重装入口，不能代替吊射干跑。

| 模式 | 干什么 | 云台 |
| --- | --- | --- |
| 吊射 | yaml 固定点、永远低抛 | 定住打点 |
| 钉头自瞄 | 小陀螺时 yaw 钉车中心，窗口内开火 | **不追板**（保护重装电机） |
| 同济默认动头自瞄 | 每帧跟踪预测装甲板 | 会狂甩，重装小陀螺别用 |

## 2. 为什么要钉头

重装云台很重。对小陀螺如果「动头追板」，电机容易烧。  
正确打法：yaw 钉在敌车中心方向，等装甲转到射界再开火。

成熟参考（远程 `jlcv-pc`）：

- `/home/jlcv/jlauto-aim/hero/src/solve_angle/src/opti_solver.cpp`
  - `processAssessment2`：四板，`|v_yaw|≥1` 时 `yaw_out = center_view_yaw`
  - `processOutpost`：前哨「定头伏击」
- 说明：`/home/jlcv/jlauto-aim/若干调试心得.md`

本仓配置：`configs/heavy_nail.yaml`（`nail_mode: true`）。

## 3. 吊射干跑验收

在仓库根目录：

```bash
cmake -B build_lob -DHEAVY_LOB_ONLY=ON
cmake --build build_lob -j$(nproc)
./build_lob/heavy_lob_offline_test
./build_lob/heavy_lob configs/heavy_lob.yaml --once
./build_lob/heavy_lob configs/heavy_lob.yaml --once --fire
./build_lob/heavy_lob configs/heavy_lob.yaml --once --undock
./build_lob/nail_aimer_offline_test
```

正常：`PASS`；`READY z=1`；`z=2`；`INHIBITED`；钉头测试打印 `PASS` 且 yaw 钉在中心附近。

## 4. 上车吊射联调（英雄电控）

串口约定抄自远程英雄 `jlauto-aim/hero` 的 `jlcv_serial_driver`：

- 口：`/dev/ttyUSB0`，波特率 `921600`
- 下发 `0xA5`（pitch/yaw/z/deploy + CRC16）
- 回传 `0x5A`（curr_pitch/curr_yaw/bullet_speed + CRC16）；弹速会写回解算

1. 复制 `configs/heavy_lob_robot.yaml`，临时 `module_unlocked/docked: true`
2. 无反馈时先 `open_loop: true`；有 0x5A 后再关开环
3. 先不加 `--fire`，看云台方向
4. `./build_lob/heavy_lob configs/heavy_lob_robot.yaml --loop --dry-run=false --port=/dev/ttyUSB0`
5. 部署模式：`--deploy=true` 或 yaml `deploy: true`（对应英雄 `deploy_mode_enabled`）
6. cutecom 核对 `a5=` 以 `a5` 开头、13 字节；`deploy=1` 时第 11 字节为 `01`

## 5. 状态怎么读

| 日志 | 含义 | 怎么办 |
| --- | --- | --- |
| `INHIBITED` | 门闩未开或未对接 | 确认模块；联调才改 yaml |
| `windmill block` | 弹道穿风车 | 改站位或风车参数 |
| `low exceeds pitch_max` | 低抛超俯仰限位 | 靠近或降目标高度 |
| `*_CONVERGING` / timeout | 闭环无反馈 | 保持 `open_loop: true` |
| `sender=DrySender` | 没写串口 | 查 port / 权限 |

## 6. 调参顺序（吊射）

符号 → `base_yaw`（**弧度**）→ 几何 → `bullet_speed` → `friction`。  
细表见 `readme.md` 第五节。

钉头 yaml：`nail_spin_on` / `nail_spin_off`（滞回）、`nail_fire_window_deg`（默认 4°）。

## 7. 禁止

- 不要跑根目录 `autostart.sh`（指向旧 `sp_vision_25`）
- 不要直接拿未改门闩的 `heavy_lob_robot.yaml` 上场
- `--loop --fire` 会持续开火
- 闭环（`open_loop: false`）目前读不到反馈
- **重装打小陀螺不要用未开 `nail_mode` 的同济动头自瞄**
