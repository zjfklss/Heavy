前哨站的装甲受击面精确 CAD 未随本模块引入，当前同样使用 2026 小装甲外形矩形。
不能将上述尺寸当作视觉算法中灯条端点的 PnP 尺寸；几何特征兼容模式使用外形角点；新的图像相机提供独立、可配置的合成灯条布局，
不声称这些灯距、灯长或字形是实机测量值，见 [CAMERA.md](../CAMERA.md)。

车辆的两组半径、局部中心高度、速度、加速度、加加速度、随机运动幅度是可调实验参数，
不声称是官方车辆统一规格。配置可以故意超出实际车辆动力学以进行算法压力测试。

本模块保留清晰的几何接触/有效命中区分，但不模拟装甲检测电路、弹丸变形、真实灵敏度和完整比赛结算。
几何与运动公式为独立实现，没有复用被测自瞄算法的预测或弹道求解代码。
