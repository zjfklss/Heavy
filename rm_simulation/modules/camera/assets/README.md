处理方法：官方 PDF 相关页按长边 1400 像素光栅化，裁取中央白色标识（去除螺钉孔、外轮廓及图注），保持宽高比缩至 78×104 范围，居中放置在 96×128 黑底，按灰度 128 二值化。
每行按低位在前打包为 12 字节，同时合并相邻行的相同白色区间供 Qt 网格绘制。两种渲染共用同一掩码。
画布投影尺寸为 90×120 mm，是当前合成成像参数；并非从无尺寸的附录图推导出的实机标定值。

车辆可选 `1/2/3/4/sentry`；前哨站由目标类型自动使用 `outpost`。同一目标各块装甲使用相同标识。
默认车辆仍为步兵 3，旧配置可以继续载入。本文资源仅对应 2026 贴纸，未实现 2027 点阵屏。
